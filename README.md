# Oferta social media dla Willa Developer

Sprzedażowa strona ofertowa przygotowana jako osobny projekt Next.js.

## Uruchomienie

```bash
npm install
npm run dev
```

## Weryfikacja

```bash
npm run typecheck
npm run build
```

Zdjęcia w `public/images` pochodzą z materiałów opublikowanych na stronie Willa Developer.
